# GridfinityStudio brand assets

The mark is an original isometric storage grid in mint and deep teal.

- `mark.svg`: scalable app mark.
- `logo-lockup.svg`: mark and wordmark for the project page.
- `mark.png`: 512px transparent PNG.
- `mark.rgba`: 128px RGBA texture embedded in the app.
- `../GridfinityStudio.ico`: Windows icon with 16–256px variants.

Palette: background `#142e32`, mint `#83e6cc`, teal `#35a18f`.
All assets are covered by the repository's MIT license.

To regenerate the PNG, RGBA and ICO files on Windows:

```powershell
.\scripts\generate-brand-assets.ps1
```

Keep the generator's geometry and `mark.svg` in sync when changing the mark.
